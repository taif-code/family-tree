# شجرة العائلة

## التشغيل
1. ثبّت Node.js (نسخة 18 أو أحدث) من https://nodejs.org
2. افتح هذا المجلد في VS Code
3. افتح الطرفية: Terminal ← New Terminal
4. اكتب:  `node server.js`   (أو `npm start`)
5. افتح المتصفح على: http://localhost:3000

## الملفات
- `public/index.html` — الصفحة كاملة (الفورم + الشجرة + السماء)
- `server.js` — سيرفر صغير يحفظ التسجيلات
- `data.json` — كل البيانات (الإعدادات والتسجيلات). ينشأ تلقائياً أول تشغيل.

## الإعدادات
قسم «إعدادات المنظّم» يظهر فقط لما تفتح الصفحة من نفس الجهاز (localhost).
منه تغيّر أسماء الأفخاذ والعدد المتوقع، وتحذف أي ورقة.

## تشغيلها لأهلك على نفس الواي فاي
لما تشغّل السيرفر يطبع لك رابط مثل http://192.168.1.5:3000
أي جوال متصل بنفس الواي فاي يقدر يفتحه ويسجّل.
